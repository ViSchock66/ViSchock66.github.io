Hermes Agent

Agente autónomo en WhatsApp conectado a base documental local, búsqueda web y herramientas MCP

Implementación
Agente de respuesta en WhatsApp 24/7 con RAG documental local, búsqueda web e integración MCP
Caso de uso
Asistente personal/comercial y de atención a consultas sobre documentación local
Desafío
Errores de system prompt, manejo de contexto y modelos que ignoraban instrucciones o alucinaban al consultar la base local
Intervención
Refinamiento de system prompts, ajuste de ventana de contexto y pruebas comparativas de modelos frente al RAG local
Resultado
Selección de modelos con recuperación documental fiel, reducción de alucinaciones y respuestas consistentes en WhatsApp

Configuré y desplegué agentes autónomos sobre Hermes Agent (NousResearch) conectados a WhatsApp 24/7, integrando un RAG documental local, búsqueda web y herramientas MCP para resolver consultas prácticas como asistente comercial y de atención al cliente.

Durante las pruebas operativas detecté fallos combinados de system prompt, ventana de contexto y elección de modelo: mientras algunos modelos recuperaban correctamente la base de datos local, otros ignoraban las reglas del prompt o alucinaban respuestas fuera del documento.

El diagnóstico consistió en aislar cada variable —estructura del system prompt, presupuesto de contexto y pruebas comparativas entre modelos— hasta lograr respuestas estables y apegadas a la base documental.
